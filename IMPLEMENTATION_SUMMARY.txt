## Scaling Model Summary

### Player Pressure Formula
```
regional_pressure = playersInRegion × pressurePerPlayer × stageMultiplier
```

**Default registration**: `PlayerPressureSource(1.0D)` in integration manager (though engine uses 0.05D)

### Stage Multipliers
| Stage | Multiplier |
| --- | ---: |
| RDP-0 | 0.5 |
| RDP-I | 0.8 |
| RDP-II | 1.0 |
| RDP-III | 1.2 |
| RDP-IV | 1.4 |
| RDP-V | 1.6 |
| RDP-VI | 1.8 |
| RDP-VII | 2.0 |
| RDP-X | 3.0 |

### Performance Characteristics
- **Time complexity**: O(P) per processed region (P = players)
- **Budget per tick**: 50 ms (Forge default)
- **Active region cache**: 1024 regions (configurable)
- **Pressure calc target**: <10 ms per tick
